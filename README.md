# Теңгерім

Теңгерім (code name and repository: **Bereke**; npm package `bereke`, Render services `bereke-web`/`bereke-api`) is a personal finance website with a React/Vinext frontend and a Django API. It supports accounts, income and expense records, monthly category budgets, subscriptions, and card labels.

For setup, database migration, email configuration, and PostgreSQL deployment notes, see [README-BEREKE.md](README-BEREKE.md).

Local development uses the frontend at `http://127.0.0.1:5187/` and the Django API at `http://127.0.0.1:8011/`.
